# Vendor-Performance-Analysis-Dashboard

1.1 Brief Overview of Work    
The Vendor Performance Analysis project is designed to analyze and evaluate vendor performance using data analytics and visualization tools such as Python, SQL, and Power BI. In today’s business environment, organizations depend heavily on vendors for procurement and supply chain operations. Therefore, analyzing vendor performance is essential for improving efficiency, reducing costs, and ensuring quality service.   
This project demonstrates how data collected from various sources can be processed using Python libraries and SQL queries to extract meaningful insights. These insights are then visualized through an interactive Power BI dashboard. The system helps in tracking key metrics such as sales, purchase quantity, profit margins, and vendor contribution over different time periods.   
By transforming raw vendor data into structured and meaningful information, the dashboard provides a clear view of vendor performance. It helps stakeholders identify top-performing vendors, detect underperforming ones, and make informed decisions to optimize business operations and vendor relationships.
